# УСН нарастающим итогом

Калькулятор налога по упрощённой системе налогообложения. Он не просто выдаёт сумму, а показывает каждый шаг расчёта с формулой и вашими числами, чтобы по нему можно было учиться.

Работает без сборки и без сервера: это обычные HTML, CSS и JavaScript.

## Как запустить

Самый простой способ: открыть `index.html` в браузере.

Если хочется запустить как маленький сайт:

```bash
npm start          # то же, что python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Тесты (нужен Node.js 20 или новее):

```bash
npm test
```

## Что внутри

| Файл | Зачем |
| --- | --- |
| `calc.js` | Вся математика УСН и текст пошагового объяснения. Без DOM, поэтому читается и тестируется отдельно. |
| `calc.test.js` | Тесты. Каждый тест это маленькая задача с ответом, который можно проверить на бумаге. |
| `app.js` | Интерфейс: читает поля, вызывает `calculate()` и `explain()`, рисует таблицу и шаги. |
| `index.html`, `style.css` | Разметка и оформление. Тёмная тема включается сама по настройкам системы. |

Схема работы одна для всего проекта:

```
ввод пользователя  →  calculate()  →  таблица, итог, подсказки
                          └────────→  explain()  →  «Как это посчитано»
```

## Как считается налог

Главная идея «нарастающего итога»: налог считают не за каждый квартал отдельно, а с 1 января до конца периода (3, 6, 9 месяцев и год). Аванс за период это разница между налогом нарастающим итогом и авансами, которые уже начислены.

### УСН «Доходы» (6%)

```
Налог по ставке = Доходы с 1 января × ставка
Предел вычета   = Налог по ставке × 100%  (ИП без работников)
                  Налог по ставке × 50%   (ИП с работниками и организации)
Вычет           = меньшее из (взносы с 1 января; предел вычета)
Налог за период = Налог по ставке − Вычет
К уплате        = Налог за период − авансы, начисленные раньше
```

### УСН «Доходы минус расходы» (15%)

```
Расходы         = расходы + страховые взносы с 1 января
База            = Доходы − Расходы
Налог по ставке = База × ставка            (если база отрицательная, налог 0)

Только по итогам года:
  База после убытка = База − меньшее из (убыток прошлых лет; база)
  Минимальный налог = Доходы × 1%
  Налог за год      = большее из (налог по ставке; минимальный налог)

К уплате        = Налог за период − авансы, начисленные раньше
```

Налог округляется до целого рубля: 50 копеек и больше округляются вверх.

### Пример с цифрами

ИП без работников, «Доходы» 6%. Доходы по кварталам: 1 450 000, 1 820 000, 2 100 000 ₽. Взносы: 14 348, 14 348, 14 347 ₽.

| Период | Доходы нарастающим | Налог 6% | Взносы нарастающим | Налог за период | Аванс к уплате |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 квартал | 1 450 000 | 87 000 | 14 348 | 72 652 | 72 652 |
| Полугодие | 3 270 000 | 196 200 | 28 696 | 167 504 | 167 504 − 72 652 = 94 852 |
| 9 месяцев | 5 370 000 | 322 200 | 43 043 | 279 157 | 279 157 − 167 504 = 111 653 |

Этот пример входит в тесты: `calc.test.js`, первый тест.

## Сроки уплаты

- Аванс за 1 квартал: до 28 апреля.
- Аванс за полугодие: до 28 июля.
- Аванс за 9 месяцев: до 28 октября.
- Налог за год: ИП до 28 апреля, организации до 28 марта следующего года.

Если 28 число выпадает на выходной, срок переносится на понедельник. Праздничные переносы калькулятор не учитывает.

## Как по этому проекту учиться

1. Откройте страницу и в блоке «Как это посчитано» пройдите шаги для каждого периода. Сравните их с таблицей выше.
2. Прочитайте `calc.js` в таком порядке: `calculate()`, затем `explain()`. Комментарии в коде объясняют, зачем нужна каждая строка.
3. Откройте `calc.test.js`. Перед тем как смотреть ответ в тесте, посчитайте его сами.
4. Сломайте формулу в `calc.js` (например, замените `Math.min` на `Math.max` в вычете) и запустите `npm test`. Посмотрите, какие тесты упали и почему.

Идеи для практики:

- Добавьте поле «Фактически уплачено авансов» и считайте аванс по нему, а не по расчёту.
- Добавьте год 2027, когда станут известны размеры фиксированных взносов.
- Добавьте ставки 8% и 20% для доходов выше повышенного порога.
- Напишите тест на ООО с 50% вычетом и убытком за год.

## Что не учтено

- Фактически уплаченные авансы: расчёт исходит из того, что вы платили ровно по расчёту.
- Повышенные ставки при больших доходах, льготы кроме пониженной ставки, торговый сбор и НДС.
- Праздничные переносы сроков.

Значения на 2026 год: фиксированные взносы ИП 57 390 ₽, предел взноса 1% с дохода свыше 300 000 ₽ составляет 321 818 ₽, лимит дохода для УСН 490,5 млн ₽, НДС на УСН при доходе свыше 20 млн ₽. Они лежат в начале `calc.js` (объект `YEARS`), и их нужно обновлять каждый год.

Расчёт справочный. Перед оплатой сверьте суммы с бухгалтером или с уведомлением в личном кабинете налогоплательщика.
